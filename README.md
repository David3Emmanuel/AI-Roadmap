### Phase 2: Exploration & Portfolio

In cycles of 2-3 months each:

1. Choose a relevant topic (foundational or trending)
2. High-level understanding (blogs, videos, courses)
3. Low-level understanding (original papers)
4. Implementation
5. Publicity (GitHub, blog, video)
